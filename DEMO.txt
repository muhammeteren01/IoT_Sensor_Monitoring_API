PulseGrid — Demo kullanım kılavuzu
==================================

Adresler
--------
UI (PulseGrid) : http://localhost:4040
API / Swagger  : http://localhost:8080
Grafana        : http://localhost:3000


1) Nasıl ayağa kaldırılır
-------------------------
Docker Desktop açık olsun. Bu klasörde (docker-compose.yml'in olduğu yerde):

  docker compose pull
  docker compose up -d

İlk açılışta 30-60 sn bekle (API migrate + seed, Worker ölçüm, Grafana org senkronu).

Durdurmak:

  docker compose down

Veriyi silmeden durur. Volume'leri de silmek (seed yeniden basılsın) için:

  docker compose down -v
  docker compose up -d


2) PulseGrid UI nasıl kullanılır
--------------------------------
Tarayıcı: http://localhost:4040

SuperAdmin ile giriş yap, şirket/tesis/bölge/cihaz modeli/sensör/kullanıcı ekle.
Sol menüden tüm kaynaklar yönetilir.

  SuperAdmin     : tüm şirketleri görür, yeni şirket/kullanıcı ekler
  CompanyAdmin   : yalnız kendi şirketini görür, o şirkete kullanıcı/tesis/sensör ekler
  Operator       : kendi şirketinde izler, sınırlı yetki

Kullanıcı ekleme self-register değil; Users ekranından POST /api/users ile eklenir
(CompanyAdmin / SuperAdmin).


3) Grafana nasıl kullanılır
---------------------------
Tarayıcı: http://localhost:3000
"Sign in with PulseGrid" tıkla.
Açılan ekrana PulseGrid e-posta/şifresini yaz.

  SuperAdmin   -> Main Org, tüm şirketler
  Şirket kullanıcısı -> yalnız kendi org / kendi verisi

Şirket kullanıcısı Viewer'dır; başka şirketin grafiğini göremez.

Acil / teknik giriş (OAuth değil):  admin / admin

İlk login'de "No data" çıkarsa: Grafana'dan çıkış yap, 20-30 sn bekle, tekrar gir.
Dashboard dolması için Worker'ın 1-2 dk ölçüm basmasını bekle.


4) API / Swagger (isteğe bağlı)
-------------------------------
http://localhost:8080
Authorize ile login token'ı yapıştırılır.
Health: http://localhost:8080/health


Seed kullanıcı
--------------
Rol          Ad            E-posta           Şifre
SuperAdmin   Super Admin   admin@iot.local   (SeedSettings.Password — varsayılan Admin123!)


Integration client (M2M / Worker ApiIntegration)
------------------------------------------------
Şirket oluşturulunca POST /api/companies yanıtında client_id + client_secret bir kez döner.

Token:
  POST http://localhost:8080/oauth/token
  grant_type=client_credentials
  client_id=...
  client_secret=...

Sensör sync:
  GET http://localhost:8080/api/sensors
  Authorization: Bearer {access_token}

Ölçüm yazma:
  POST http://localhost:8080/api/sensor-measurements
  Authorization: Bearer {access_token}

Worker ApiIntegration (Faz 3 — SQLite offline queue):
  WorkerExecution__Mode=ApiIntegration
  IntegrationSettings__ApiBaseUrl=http://localhost:8080  (Docker: http://api:8080)
  IntegrationSettings__LocalStorePath=data/worker-queue.db  (Docker: /app/data/worker-queue.db)
  IntegrationSettings__Clients__0__ClientId=...
  IntegrationSettings__Clients__0__ClientSecret=...
  DirectDb Worker ile aynı anda çalıştırma (çift ölçüm).
  API down → queue dolar; API up → flush + silme; MeasurementDate ölçüm anıdır.

Grafana acil:  admin / admin
Grafana şirket:  Sign in with PulseGrid  +  PulseGrid e-posta/şifre
