PulseGrid — Demo kullanım kılavuzu
==================================

Adresler
--------
UI (PulseGrid) : http://localhost:4040
API / Swagger  : http://localhost:8080
Grafana        : http://localhost:3000

Tüm seed kullanıcı şifresi:  Admin123!


1) Nasıl ayağa kaldırılır
-------------------------
Docker Desktop açık olsun. Bu klasörde (docker-compose.yml'in olduğu yerde):

  docker compose pull
  docker compose up -d

İlk açılışta 30-60 sn bekle (API migrate + seed, Worker ölçüm, Grafana org senkronu).

Durdurmak:

  docker compose down

Veriyi silmeden durur. Volume'leri de silmek (seed yeniden basılsın) için:

  docker compose down -v
  docker compose up -d


2) PulseGrid UI nasıl kullanılır
--------------------------------
Tarayıcı: http://localhost:4040

Giriş yap (aşağıdaki hesaplardan biri).
Sol menüden şirket, tesis, bölge, cihaz modeli, sensör, kullanıcı, alarm yönetilir.

  SuperAdmin     : tüm şirketleri görür, yeni şirket/kullanıcı ekler
  CompanyAdmin   : yalnız kendi şirketini görür, o şirkete kullanıcı/tesis/sensör ekler
  Operator       : kendi şirketinde izler, sınırlı yetki

Kullanıcı ekleme self-register değil; Users ekranından POST /api/users ile eklenir
(CompanyAdmin / SuperAdmin).

Çıkış: sağ üstten logout, başka hesapla tekrar gir.
Tenant ayrımını göstermek için Nova ile gir, sonra çıkıp Atlas ile gir;
Atlas, Nova sensörlerini görmez.


3) Grafana nasıl kullanılır
---------------------------
Tarayıcı: http://localhost:3000
"Sign in with PulseGrid" tıkla.
Açılan ekrana PulseGrid e-posta/şifresini yaz (örn. ayse.kaya@nova.local).

  Nova hesabı  -> yalnız Nova org / Nova verisi
  Atlas hesabı -> yalnız Atlas org / Atlas verisi
  SuperAdmin   -> Main Org, tüm şirketler

Şirket kullanıcısı Viewer'dır; başka şirketin grafiğini göremez.

Acil / teknik giriş (OAuth değil):  admin / admin

İlk login'de "No data" çıkarsa: Grafana'dan çıkış yap, 20-30 sn bekle, tekrar gir.
Dashboard dolması için Worker'ın 1-2 dk ölçüm basmasını bekle.


4) API / Swagger (isteğe bağlı)
-------------------------------
http://localhost:8080
Authorize ile login token'ı yapıştırılır.
Health: http://localhost:8080/health
